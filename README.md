# 🔍 منصة "مكشاف" (MIKSHAF) — وحدة التحقيق الجنائي الرقمي وكشف التزييف

> **"ملف قضية محقق رقمي" (Detective Case File) لكشف الصور المفبركة، التزييف العميق (Deepfakes)، والأخبار المضللة عبر الذكاء الاصطناعي.**

---

## 📑 نبذة عن المشروع والرؤية
**مكشاف (MIKSHAF)** هو تطبيق ويب متكامل ومبتكر يكشف التلاعب في الوسائط الرقمية:
1. **فحص الصور والوسائط**: كشف الصور المولدة بنماذج الذكاء الاصطناعي (Midjourney, DALL-E, Stable Diffusion, Flux)، صور التزييف العميق للوجوه (Deepfakes)، والتعديلات التركيبية في الإضاءة والظلال.
2. **فحص النصوص وروابط الويب (URLs)**: فحص الأخبار والادعاءات المضللة، جلب محتوى المقالات من روابط الإنترنت وتحليلها، وكشف البصمات الأسلوبية لنصوص الذكاء الاصطناعي (LLMs مثل ChatGPT وClaude).

### 🕵️ الهوية الإبداعية — طابع "ملف قضية محقق":
- **ختم الحكم النهائي (Rubber Stamp)**: حركة دقّة ختم قوية بثلاث حالات: حقيقي (`AUTHENTIC`) بالأخضر، مزيّف (`FAKE`) بالأحمر المحروق، وغير مؤكد (`UNCERTAIN`) بالأصفر الخردلي.
- **عداد الثقة الدائري (Trust Score)**: مؤشر بصري تفاعلي من 0 إلى 100%، مصحوباً بنسبة احتمال التوليد الآلي.
- **لوحة الأدلة والقرائن (Evidence Board)**: بطاقات ملاحظات مثبتة بدبوس ومائلة بزوايا خفيفة، مع شريط لوني يميز الأدلة الداعمة عن المؤشرات المشبوهة وإمكانية تصفيتها.
- **شاشة تحقيق جنائي حركية**: سلسلة رسائل فحص تتغير كل 1.8 ثانية تحاكي خطوات التقصي المعملي.
- **نظام نقاط اليقظة الرقمية (Digital Vigilance Score)**: نظام مستويات ورتب للمستخدم (مبتدئ ← يقظ ← خبير ← رئيس الأدلة الجنائية) يمنحك +25 نقطة عن كل قضية.
- **أرشيف القضايا (Case Archive)**: حفظ محلي تلقائي في المتصفح لجميع الفحوصات السابقة مع إمكانية استعراض وتصدير أي قضية.
- **دعم ثنائي اللغة بالكامل (العربية والإنجليزية)**: مع تبديل فوري لاتجاه الواجهة (RTL / LTR).
- **أسلوب Neo-Brutalism**: حدود سوداء بارزة، ظلال صلبة، خلفية ورقية دافئة، وخطوط كلاسيكية مستوحاة من الآلة الكاتبة وتقارير المباحث.

## 🔑 كيفية الحصول على مفتاح Gemini API مجاناً (خطوة بخطوة)

1. ادخل إلى موقع **[Google AI Studio](https://aistudio.google.com/)**.
2. سجّل الدخول بحساب Google الخاص بك.
3. اضغط على الزر الأزرق الكبير في أعلى اليسار أو القائمة: **"Get API key"** (الحصول على مفتاح API).
4. اضغط على **"Create API key"** (إنشاء مفتاح في مشروع جديد أو مشروع موجود).
5. سيظهر لك مفتاح طويل يبدأ عادةً بـ `AIzaSy...`، اضغط على زر **Copy** لحفظه.
> ⚠️ **ملاحظة أمان هامة**: لا تشارك هذا المفتاح مع أحد أبداً، ولا تضعه في أي كود مرئي للمتصفح.

## 💻 تشغيل المشروع محلياً على جهازك (Local Development)

### 1. تثبيت المتطلبات:
تأكد من تثبيت بيئة **[Node.js](https://nodejs.org/)** (الإصدار 18 أو أحدث).

### 2. تجهيز المفتاح السري:
قم بإنشاء ملف باسم `.env` في المجلد الرئيسي للمشروع وضع بداخله:
```env
GEMINI_API_KEY="ضع_مفتاحك_هنا_بدون_أقواس"
```

### 3. تثبيت المكتبات وتشغيل التطبيق:
افتح موجه الأوامر (Terminal) في مجلد المشروع واكتب:
```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على الرابط:
```
http://localhost:3000
```

## 🚀 كيفية نشر المشروع على Netlify (خطوة بخطوة)

تطبيق مكشاف يدعم التشغيل كـ Full-Stack بنقرة واحدة عبر Netlify:

### الخطوة 1: رفع المشروع على GitHub
قم بإنشاء مستودع جديد على حسابك في GitHub وارفع ملفات المشروع إليه (ملف `.env` مستثنى تلقائياً عبر `.gitignore`).

### الخطوة 2: الربط مع Netlify
1. ادخل إلى **[Netlify.com](https://www.netlify.com/)** وسجل دخولك بحساب GitHub.
2. اضغط على **"Add new site"** ثم اختر **"Import an existing project"**.
3. اختر مستودع مشروع "MIKSHAF" الخاص بك.

### الخطوة 3: إضافة مفتاح API السري بأمان
1. قبل الضغط على Deploy، توجه إلى قسم **"Environment variables"** (أو بعد الإنشاء من Site configuration > Environment variables).
2. اضغط على **"Add a variable"**.
3. في خانة **Key** اكتب: `GEMINI_API_KEY`
4. في خانة **Value** ضع المفتاح الذي نسخته من Google AI Studio (`AIzaSy...`).
5. اختر تطبيق المتغير على كافة البيئات (All scopes: Production, Deploy Previews, Branch deploys).

### الخطوة 4: إعدادات البناء (Build settings)
- **Build command**: `npm run build`
- **Publish directory**: `dist`
- اضغط على **"Deploy site"**.

خلال دقيقة واحدة سيكون موقعك منشوراً ومتاحاً على رابط عالمي سريع ومؤمن بشهادة SSL مجانية! 🎉
